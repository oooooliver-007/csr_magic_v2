## Purpose

定义管理端控制台（`/admin/**`）的 UI 行为契约：在移动视口下页面不得横向溢出、关键工具栏呈可预期的对齐网格；管理端操作按钮统一品牌色，不得残留与品牌色冲突的蓝/黑底色。

## ADDED Requirements

### Requirement: 管理端页面在移动视口不得横向溢出

管理端全部页面（数据看板、事件管理、活动管理、参与审核、问卷管理、用户管理）SHALL 在 390px 宽移动视口下无横向页面溢出（页面滚动宽度不大于视口宽度）。

#### Scenario: 手机视口遍历管理端页面

- **WHEN** 以 390×844 视口逐页访问管理端全部页面
- **THEN** 每页 `document.documentElement.scrollWidth ≤ clientWidth`，无横向滚动

### Requirement: 问卷管理头部移动端堆叠布局

问卷管理页头部 SHALL 在移动视口下按「标题块 → 问卷计数 → 操作按钮」顺序堆叠：计数独占一行，两个操作按钮等分同一行，按钮组左右边缘与页面内容边缘对齐（坐标差 < 2px）；桌面端布局保持不变。

#### Scenario: 手机视口问卷管理头部

- **WHEN** 以移动视口打开问卷管理页
- **THEN** 「AI 生成问卷」与「手动创建问卷」按钮等宽同行，左右边缘与「问卷管理」标题对齐，无挤压溢出

### Requirement: 活动管理工具栏移动端对齐网格

活动管理页筛选工具栏 SHALL 在移动视口下按「搜索框整行 → 事件/状态两个下拉等分一行 → 新建活动按钮整行」排列，各行左右边缘相互对齐（坐标差 < 2px）；桌面端保持「搜索 256px + 筛选下拉 + 右侧按钮」原布局。

#### Scenario: 手机视口活动管理工具栏

- **WHEN** 以移动视口打开活动管理页
- **THEN** 搜索框、两个下拉、新建按钮的左右边缘两两对齐，无控件被挤压截断

### Requirement: 管理端操作按钮统一品牌色

管理端页面的主动作按钮（含问卷管理的 AI 生成问卷、手动创建问卷、AI 生成题目及各弹窗保存按钮）SHALL 使用品牌绿 `#2EB87A`（hover 态 `#2EB87A`/90），不得出现与品牌色冲突的蓝底/黑底按钮；信息性配色（如题目类型徽章、图表）不受此约束。

#### Scenario: 问卷管理按钮颜色检查

- **WHEN** 打开问卷管理页并读取各主动作按钮的计算样式
- **THEN** 背景色均为 `rgb(46, 184, 122)`，页面内无 `bg-blue-600`/`bg-gray-800` 底色按钮残留
