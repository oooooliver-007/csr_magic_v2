## Purpose

管理端（Admin）整体布局与导航的行为契约：规定管理端在桌面端与窄屏（移动端）下均可操作，窄屏通过抽屉式侧边栏提供导航。

## ADDED Requirements

### Requirement: 管理端在窄屏下可通过抽屉导航

管理端在窄屏（视口宽度小于桌面断点）下必须提供可用的导航方式：页面顶部显示汉堡菜单按钮，点击后从屏幕侧边滑出抽屉式侧边栏，带遮罩，可选择菜单项并收起抽屉。桌面端保持固定的左侧边栏。

#### Scenario: 窄屏打开抽屉导航
- **WHEN** 用户在窄屏设备上进入任一 Admin 页面
- **THEN** 页面显示汉堡菜单按钮，点击后侧边栏以抽屉形式滑出并覆盖遮罩

#### Scenario: 窄屏选择菜单项并收起
- **WHEN** 用户在窄屏抽屉中选择一个菜单项
- **THEN** 抽屉收起并跳转到对应管理页面

#### Scenario: 点击遮罩收起抽屉
- **WHEN** 窄屏抽屉打开且用户点击遮罩区域
- **THEN** 抽屉收起，当前页面保持不变

#### Scenario: 桌面端保持固定侧栏
- **WHEN** 用户在桌面端进入任一 Admin 页面
- **THEN** 左侧固定侧边栏完整显示，主内容区不被侧栏遮挡

### Requirement: 管理端页面在窄屏下可操作

所有 Admin 功能页面（数据看板、事件管理、活动管理、问卷管理、参与审核、用户管理）必须在窄屏下保持核心操作可用：工具栏/筛选/分页/弹窗/详情面板不超出屏幕宽度且可交互。

#### Scenario: 窄屏浏览列表并操作
- **WHEN** 用户在窄屏设备上打开任一 Admin 列表页面（如活动管理、参与审核）
- **THEN** 列表以移动友好的卡片形式呈现，筛选、分页与行操作均可正常使用

#### Scenario: 窄屏打开弹窗不溢出
- **WHEN** 用户在窄屏设备上打开任何 Admin 弹窗（表单、详情、确认框）
- **THEN** 弹窗宽度不超过视口宽度，内容可滚动，按钮可操作

#### Scenario: 窄屏切换顶部通知待办入口
- **WHEN** 用户在窄屏设备上浏览 Admin 页面
- **THEN** 顶部待审核待办入口（AdminReviewTodoBell）可见且可点击，不与其他元素重叠
